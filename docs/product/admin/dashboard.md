# Admin · Dashboard

`/` — where signing in lands, and where anything unrecognised falls back.

**The page is empty on purpose.** What a back-office dashboard should show is a product question
nobody has answered yet, and filling the space with three counters would make that question
harder to ask, not easier. It says so, and waits.

## Open question

What belongs here. Candidates worth weighing when the question is opened: accounts signed up
recently, accounts never signed in, deactivations in the last month, the size of the reference
sets. None of them is obviously worth a screen yet.
